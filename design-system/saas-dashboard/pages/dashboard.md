# Dashboard page overrides

Overrides `MASTER.md` for `/dashboard/[tenantId]`.

## Layout rules

- Shell sidebar = module navigation (CRM, workflow, settings route…)
- Home page segment control = only **Genel Bakış / Randevular / Ayarlar (inline)**
- WhatsApp + QR only in sidebar (no duplicate header buttons)
- Primary CTA on home: **Randevu Ekle** (emerald)

## Visual

- Active nav: emerald, not black
- KPI tiles: `panel-muted`, no shadows
- Alerts: left border severity, not full gradient cards
- No emoji icons
